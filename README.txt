# Ameyra + Jasmine — Minecraft-style love website

## Add your own photos
Open the `photos` folder and put your pictures there.
Rename them:
photo1.jpg
photo2.jpg
photo3.jpg
...
You can add up to 50 photos. The website automatically displays whichever ones exist.

## Open the website
Open `index.html` in a browser. To share it with Ameyra as a normal link, upload the whole folder to a static website host.
